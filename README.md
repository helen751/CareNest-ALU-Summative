# Overview

CareNest is a web-based Child Health Support System designed to help mothers and guardians make better healthcare decisions for their children.

The application guides caregivers through AI-generated health assessments, classifies symptoms into different severity levels, provides personalized recommendations, supports appointment booking, and identifies nearby hospitals for urgent situations.

The project was developed as part of the Bachelor of Software Engineering program at the African Leadership University.

> **Disclaimer**
>
> CareNest is **not** intended to replace professional medical advice or diagnosis. The recommendations generated by the system are meant only as basic guidance and should always be followed by consultation with qualified healthcare professionals where necessary.

---

# Problem Statement

Many mothers and guardians are often the first people to notice changes in a child's health.

Unfortunately, they may not know:

- whether the symptoms are minor,
- whether they require medical consultation,
- or whether they require immediate hospital attention.

This uncertainty can lead to:

- delayed treatment,
- unnecessary panic,
- self-medication,
- reliance on unverified internet advice,
- or preventable complications.

CareNest was built to bridge this gap by helping caregivers understand what action should be taken after assessing a child's symptoms.

---

# Solution

CareNest combines several healthcare-support services into one platform.

The system allows a guardian to:

- Create an account
- Register one or more children
- Complete AI-powered symptom assessments
- Receive personalized recommendations
- View assessment history
- Book medical appointments
- Locate nearby hospitals during emergencies and share assessment summary with them
- Receive assessment reports by email

The platform uses AI together with predefined system logic to guide users toward appropriate next steps based on the severity of the child's condition.

# Database Setup

CareNest stores all application data inside a MySQL database.

The supplied SQL file contains all required tables.

```
carenest.sql
```

---

## Step 1 — Create the Database

Open MySQL.

```bash
mysql -u root -p
```

Create the database.

```sql
CREATE DATABASE carenest
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

---

## Step 2 — Create a Database User

Use the database root user or create one if you wish and change the config.php file to the new database user you created

---

## Step 3 — Import the Database

Import the supplied SQL file.

Example:

```bash
mysql -u root -p carenest < carenest.sql
```

# Configuring External APIs

Several features require API keys.

---

## Google Gemini API

Gemini powers:

- Assessment question generation
- Personalized recommendations

### Steps

1. Visit Google AI Studio.
2. Create a project.
3. Generate an API Key.
4. Copy the key.
5. Create `gemini-config.php` in the project root and add the key using the format below.

The private Gemini key is not shared in this repository. The local configuration must follow the same variable names used by `gemini.php`:

```php
<?php
$geminiKey = 'YOUR_GEMINI_API_KEY';
$geminiModel = 'gemini-flash-latest';
?>
```

`gemini-config.php` is excluded through `.gitignore` and should not be committed.

---

## EmailJS

EmailJS sends assessment reports to guardians.

Create an EmailJS account.

Create:

- Email Service
- Email Template

Copy:

- Public Key
- Service ID
- Template ID

Replace the placeholders inside the JavaScript.

Example:

```javascript
emailjs.init({
    publicKey: "YOUR_PUBLIC_KEY"
});
```

Update:

```javascript
emailjs.send(
    "YOUR_SERVICE_ID",
    "YOUR_TEMPLATE_ID",
    templateParams
);
```

# Using the Application

After logging in, the recommended workflow is:

1. Register a child profile.
2. Start a health assessment.
3. Answer all AI-generated questions.
4. Review the assessment result.
5. Book an appointment if the result is Medium Severity.
6. Locate a nearby hospital if the result is High Severity.
7. Check your email for the assessment report.
8. View previous assessments from the dashboard.
9. Monitor system usage through the Impact Dashboard.

# Troubleshooting

| Problem | Check |
|---------|-------|
| Database connection fails | Credentials and database name in `config.php` |
| AI questions do not load | Gemini API key and server internet access |
| Emails are not received | EmailJS service, template, public key, and spam folder |
| Nearby hospitals do not load | Location permission and Geoapify API key |
| Login does not persist | PHP sessions and browser cookies |

---

# Security

- Use HTTPS in production.
- Keep database and API credentials private.
- Use restricted production API keys and rotate exposed keys.
- Validate all input on both the frontend and backend.
- Back up the database regularly.
